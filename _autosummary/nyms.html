nyms#

nyms: reversible pseudonymisation of text before it reaches an AI.

A deterministic (non-AI) pass detects personal and sensitive identifiers in Danish and English text, replaces them with surrogates from a configurable strategy, remembers the mapping per project so the same person is the same pseudonym in every document, and puts the originals back into whatever the AI answers.

>>> from nyms import Pseudonymiser
>>> p = Pseudonymiser(store={})
>>> p.pseudonymise("Mail hans.jensen@example.dk, tlf. 12 34 56 78").text
'Mail [EMAIL_1], tlf. [PHONE_1]'

nyms.gazetteer_detector(names, *, name='gazetteer', entity_type='PERSON', score=1.0, surname_tail=True, value_of_name=None, single_word_score=0.85)[source]#

A detector for a list of known names (full names or first names), case-insensitive.

A first name followed by capitalised words extends to the full name when surname_tail is true. A genitive s on the last word stays in the span; the mapping store decides whether it is a genitive of a known value. value_of_name may map the matched text to the canonical value it stands for (a surname to the full name).

>>> d = gazetteer_detector(['Rasmus'])
>>> [s.text for s in d('Rasmus Jensens bil, og Rasmus selv.')]
['Rasmus Jensens', 'Rasmus']
Return type:

Detector

nyms.known_values_detectors(records, *, extra_names=(), score=1.0)[source]#

Detectors for what a project already knows: its values, their name components, its surrogates.

  • every original in the mapping, by type: names through gazetteer_detector() (word boundaries, genitive), everything else literally;

  • for persons, each component (first name or surname) that identifies exactly one known person, standing for the full name (Span.value), scored above a lone first name from the bundled list so the known person wins;

  • every surrogate already issued, as SURROGATE_TYPE, so the project’s own surrogates are never re-detected as names when pseudonymised text is processed again.

Return type:

list[Detector]

nyms.words_from_bytes(data, *, n=2, wordlist=None)[source]#

Render data as n words from wordlist (default: the EFF short list).

The integer value of the bytes is written in base len(wordlist); the lowest n digits become words. Each word of the default list carries log2(1296) = 10.3 bits, so two words identify about 1.7 million values and three about 2.2 billion.

>>> words_from_bytes(bytes([0, 0, 0, 1]), n=2)
['aardvark', 'abandoned']
Return type:

list[str]
